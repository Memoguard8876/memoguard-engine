# Security policy

MemoGuard scans supported decoded Stellar fields before submission. A clean result is not a guarantee that every sensitive value was found. Never submit real private data as a test case.

This pilot has not had a formal security audit. Treat unsupported or opaque fields as uninspected, not safe.

## Report a vulnerability

Do not post exploit details, private transaction payloads, keys, or tokens in a public issue. Use GitHub private vulnerability reporting for this repository if available. If that option is not shown, contact the organization maintainers privately through GitHub to arrange a confidential reporting channel.

Include the affected version, a minimal synthetic reproduction, expected and observed behavior, and the impact. Keep any matched values out of logs and screenshots.

## Supported versions

The latest tagged release and current `main` branch receive security fixes. Older tags are not maintained.
